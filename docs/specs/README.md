# Specs

Uma spec por fase do [roadmap](../roadmap.md), escrita antes da execução
(skill `plan-before-execute`, agent `arquiteto`).

Nome: `NN-<tema>.md` (ex.: `01-multi-module-build.md`). Cada spec traz:
objetivo, fatias ordenadas com dependências, arquivos por fatia, API pública
afetada, testes e amostras, riscos, critérios de aceite verificáveis e
perguntas em aberto.
